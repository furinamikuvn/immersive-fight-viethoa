## 🚀 Hướng Dẫn Cài Đặt

### Cách 1: Cài Đặt 1 Chạm (Khuyến Nghị Cho Mọi Người Chơi)
1. Tải tệp `Immersive Fight 4.2.9 - Viet Hoa (Forge 1.20.1).zip` từ mục **Releases**.
2. Mở Launcher Minecraft bạn đang sử dụng (*Prism Launcher, CurseForge, TLauncher, Modrinth App...*).
3. Tạo một profile hoặc phiên bản **Forge 1.20.1** (khuyến nghị phiên bản Forge `47.3.0` trở lên).
4. Mở thư mục chứa game của phiên bản vừa tạo.
5. Giải nén và **dán đè toàn bộ** các thư mục/tệp trong file zip (*config, ftbquests, global_packs, hotai, minemenu, mods, resourcepacks, resources, shaderpacks, options.txt...*) vào thư mục game.
6. Bấm **Vào game (Play)** và tận hưởng thế giới Souls-like Việt hóa!

### Cách 2: Dành Cho Người Đã Có Sẵn Modpack Gốc
1. Tải tệp `IMF-VietHoa.zip` từ mục **Releases**.
2. Bỏ file `IMF-VietHoa.zip` vào thư mục `resourcepacks/` trong game của bạn.
3. Vào game -> **Tùy chọn (Options)** -> **Gói tài nguyên (Resource Packs)** -> Kéo `IMF-VietHoa` lên vị trí kích hoạt ưu tiên.
4. *(Tùy chọn cho Sổ nhiệm vụ)*: Sao chép toàn bộ 23 file trong thư mục [`dist/quests/chapters`](file:///dist/quests/chapters) của repo này dán đè vào `config/ftbquests/quests/chapters/`.

## ⚙️ Thứ Tự Resource Pack Khuyến Nghị

Để đảm bảo hiệu ứng vệt chém kiếm quang, hoạt ảnh chiến đấu và giao diện không bị ghi đè sai lệch, vui lòng sắp xếp thứ tự gói tài nguyên trong menu Cài đặt như sau:

```
1. Better-Leaves-9.3 (Lá cây rậm rạp - Tùy chọn)
2. IMF-Trail (Vệt chém kiếm quang)
3. IMF-Modify (Cấu hình sửa đổi chiến đấu)
4. IMF-VietHoa (Gói Việt hóa ngôn ngữ)
5. BDHill Reforge the Sword Edge 沉浸特供
6. Reimagined (Gói giao diện/texture chính)
7. Fragmentum Layer (Dưới tầng này là tài nguyên nội bộ của các Mod)
```

> ⚠️ **LƯU Ý:** Khi thay đổi gói tài nguyên hoặc bấm `F3 + T` (nạp lại tài nguyên), hoạt ảnh chiến đấu có thể bị lệch. Bạn nên khởi động lại game để modpack nạp chuẩn xác nhất.
